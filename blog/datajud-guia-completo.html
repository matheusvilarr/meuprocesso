DataJud: guia completo para consultar qualquer processo do Brasil

Equipe Meu Processo · 24 de junho de 2026 · 7 min de leitura

Criado pelo Conselho Nacional de Justiça em 2020, o DataJud é hoje a maior base de dados processuais do país. Reúne informações de mais de 90 tribunais brasileiros em um único sistema, acessível de forma gratuita, e poucos advogados exploram todo o seu potencial.

Neste guia você vai entender o que é o DataJud, o que é possível consultar, quais são suas limitações reais e como usar essa ferramenta no dia a dia do escritório.

O que é o DataJud

O DataJud (Base Nacional de Dados do Poder Judiciário) é uma iniciativa do CNJ para centralizar dados processuais de todos os ramos da Justiça brasileira: estadual, federal, trabalhista, militar, eleitoral e os tribunais superiores.

Os tribunais são obrigados a alimentar o sistema com dados dos processos em andamento, incluindo movimentações, classe processual, assunto, órgão julgador e datas. A atualização é diária, mas o intervalo real entre uma movimentação no tribunal e sua aparição no DataJud pode variar de algumas horas a alguns dias, dependendo do tribunal.

A consulta é feita via API pública, o que significa que qualquer sistema pode integrar com o DataJud para buscar informações processuais de forma automatizada. É exatamente o que plataformas de monitoramento processual fazem.

O que você pode consultar

A API pública do DataJud permite buscar processos por diferentes critérios:

  • Número CNJ: o número único do processo no formato NNNNNNN-DD.AAAA.J.TT.OOOO. É a forma mais precisa e direta de consulta.
  • Número OAB: busca todos os processos em que um advogado com aquela inscrição aparece como representante de alguma das partes.
  • Nome das partes: útil quando você não tem o número do processo, mas conhece o nome do autor ou réu.
  • CPF/CNPJ: quando disponível, permite encontrar processos de uma pessoa física ou jurídica específica.

Para cada processo encontrado, o DataJud retorna:

  • Dados de identificação (número, classe, assunto, tribunal)
  • Órgão julgador responsável
  • Data de ajuizamento
  • Grau de jurisdição
  • Lista de movimentações com data e descrição
  • Dados das partes (com restrições de LGPD)

Entendendo o número CNJ

O número CNJ é a chave do DataJud. Ao contrário dos números antigos de cada tribunal, o número CNJ segue um padrão nacional:

NNNNNNN-DD.AAAA.J.TT.OOOO

NNNNNNN = número do processo (7 dígitos)
DD = dígitos verificadores
AAAA = ano de distribuição
J = segmento da justiça (1=Federal, 2=Trabalhista, 3=Eleitoral, 4=Militar, 5-9=Estadual)
TT = código do tribunal
OOOO = código do órgão

Se você tiver um número de processo antigo (pré-CNJ), é possível encontrar o número novo buscando pelo nome das partes ou pela OAB no DataJud. A maioria dos portais dos próprios tribunais já exibe o número CNJ atualmente.

Cobertura: quais tribunais estão no DataJud

O DataJud cobre os principais tribunais brasileiros, entre eles:

  • Todos os Tribunais de Justiça estaduais (TJ)
  • Tribunais Regionais Federais (TRF 1 a 6)
  • Tribunais Regionais do Trabalho (TRT)
  • Tribunais Superiores: STJ, TST, TSE, STM
  • Supremo Tribunal Federal (STF)

A cobertura não é 100% uniforme: alguns tribunais menores têm atrasos ou lacunas na alimentação do sistema. Mas para a grande maioria dos processos que tramitam no país, o DataJud é a fonte mais confiável disponível sem precisar fazer login em cada portal.

Limitações que você precisa conhecer

O DataJud é poderoso, mas tem limitações reais que todo advogado deve ter em mente:

Atraso na atualização

A movimentação aparece no tribunal hoje, mas pode levar de 1 a 5 dias para aparecer no DataJud, dependendo do tribunal. Para processos urgentes, a consulta direta ao portal do tribunal pode ser necessária.

Restrições de LGPD

Os dados das partes são protegidos pela Lei Geral de Proteção de Dados. O DataJud retorna informações básicas sobre as partes, mas CPF, CNPJ e outros dados sensíveis podem aparecer mascarados ou omitidos dependendo do tribunal e do tipo de processo.

Processos em segredo de justiça

Processos que tramitam em segredo de justiça não aparecem nas buscas públicas do DataJud. Para acessá-los, é necessário autenticação como advogado da causa.

Dados históricos incompletos

Processos muito antigos, distribuídos antes da implantação do DataJud em determinado tribunal, podem ter histórico incompleto ou não constar na base.

Como usar o DataJud na prática

O portal datajud.cnj.jus.br é o acesso mais direto e funciona sem cadastro. A busca por número CNJ é a mais rápida: cole o número no campo de pesquisa, selecione o tribunal correspondente no filtro lateral e você vê as movimentações em ordem cronológica.

Para busca por OAB, acesse a aba "Pesquisa Avançada" e selecione o campo "Representante". Digite o número da OAB com o estado no formato correto (ex: DF12345). O sistema retorna todos os processos em que aquela inscrição consta como representante, em qualquer tribunal coberto.

Um detalhe importante: o DataJud exibe as movimentações por ordem de data de atualização no sistema, não necessariamente por data de ocorrência no tribunal. Quando você estiver conferindo um prazo, sempre confira também a data original da decisão no portal do tribunal, pois a data de entrada no DataJud pode ser diferente.

Para acompanhamento contínuo, o portal não tem sistema de alerta. Você precisaria acessar manualmente toda vez que quiser verificar se houve movimentação. A alternativa é usar a API pública do DataJud integrada a um sistema de gestão, que automatiza essa verificação periódica e te avisa quando algo muda.

Conclusão

O DataJud representa uma mudança estrutural na forma como os dados processuais são acessados no Brasil. Pela primeira vez, é possível consultar processos de diferentes tribunais em uma única fonte, com um padrão uniforme de dados.

Para o advogado, isso significa não precisar conhecer e acessar o sistema de cada tribunal individualmente. Aprender a usar o DataJud diretamente é o primeiro passo. Integrá-lo com um sistema que verifique automaticamente e te avise por e-mail é o segundo.

O Meu Processo usa a API do DataJud para monitorar seus processos automaticamente e avisar por e-mail quando houver movimentação nova. Gratuito, sem limite de processos.
