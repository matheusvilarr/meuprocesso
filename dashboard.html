Acesso restrito no DataJud
A API pública do CNJ não disponibiliza dados de partes, advogados ou documentos por questões de LGPD.
Para usar esta busca você precisa solicitar acesso à API restrita do DataJud:
datajud-wiki.cnj.jus.br — Solicitar acesso
Enquanto isso, use a aba Número CNJ para buscar processos pelo número completo.
O tribunal é detectado automaticamente pelo número.
Arquivar processo
Antes de arquivar, saiba o que muda:
  • O processo sai da lista principal e do Dashboard
  • As notificações de novas movimentações serão pausadas
  • A sincronização automática com o CNJ DataJud será interrompida
  • Prazos e tarefas vinculados não serão mais exibidos no calendário
Isso é reversível. O processo ficará disponível em Arquivados & Encerrados e pode ser restaurado a qualquer momento.
